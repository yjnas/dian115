# 115 转存离线助手

Tampermonkey 用户脚本。它会在网页中识别已经出现的 115 分享、磁力和 ED2K 链接，并在链接旁提供转存或离线操作；也支持手填 Cookie 浏览 115 目录，以及向 DIAN115 外部推送。

许可证：MIT。允许使用、修改和再分发，但须保留许可证及版权声明。

## 功能

- 识别 115 分享链接、`115CID`、magnet 和 ED2K。
- 会识别浏览器当前地址栏中的 115 分享链接，即使页面正文没有重复显示该链接。
- 通过 Cookie 浏览 115 目录，选择转存和离线任务的目标目录。
- 影巢、观影和癫影页面只在真实链接已经显示或接口返回后提供操作按钮。
- 不会自动点击“解锁”“获取”或其他站点按钮。请先在原站完成正常解锁，再使用脚本识别出的链接。
- 115 分享显示“转存”，magnet/ED2K 显示“离线”，115CID 只用于设置目标目录。
- 支持“全部转存”“全部离线”和“依次推送全部”；批量任务按每秒最多两项顺序执行。
- 支持 DIAN115 外部推送，推送来源固定为“转存助手”。
- 外部推送面板按需读取 DIAN115 订阅列表，同一剧集的多季只显示一条；列表仅显示“标题（年份）”，并可逐条跳转 TMDB 或影巢媒体页。
- 右下角只有一个“已识别”入口；可在设置中切换为始终显示。入口使用 115 网站图标，识别到内容时显示数量和勾选标记。
- 页面旁操作按钮会测量页面控件并自动尝试右、左、下、上等空位；极端情况下所有位置都冲突时，选择重叠面积最小的位置，按钮不会被隐藏。

## 安装

1. 安装 Tampermonkey。
2. 新建用户脚本，将 [`dian115-p115c.user.js`](./dian115-p115c.user.js) 的内容粘贴进去并保存。
3. 首次使用时允许脚本访问 115 域名和你配置的 DIAN115 地址。

未识别到有效链接时，页面右下角不会显示助手入口。需要修改 Cookie 或外部推送配置时，可从 Tampermonkey 菜单打开“115 转存离线助手”。

## 直接连接 115

1. 手填 115 Cookie。可粘贴纯 Cookie，也可粘贴以 `Cookie:` 开头的值。
2. 点击“浏览并选择”，按 CID 节点逐级进入目录并选择当前目录。远程名称按 115 返回值原样显示和保存。
3. 页面识别到真实链接后，点击旁边的转存或离线按钮。也可在面板手动输入并识别。

115 请求通过 `GM_xmlhttpRequest` 的 `Cookie` 请求头发送。Cookie 和 OpenAPI Key 输入位于闭合 Shadow DOM，配置保存在油猴私有存储。

转存是非幂等操作，脚本只发一次 `share/receive`。如果网络层无法确认结果，必须先到 115 核对，不要立即重试。

## 面板配置

“待处理内容（可选）”用于手动粘贴要处理的链接：

- 115 分享链接：执行转存。
- magnet 或 ED2K：提交离线任务。
- 普通 HTTP(S) 离线地址：按离线任务提交。
- 115CID：只设置目标目录，例如 `115CID:123456`，它本身不是文件链接。

“115 Cookie”用于访问你的 115 账号目录。点击“浏览并选择”后，可以逐级进入文件夹并选择保存位置。

“外部推送”只需填写 DIAN115 地址和 OpenAPI Key。推送请求中的 `source` 已固定为“转存助手”，面板不会再显示或要求填写该字段。

填写后可点击“DIAN115 订阅列表”。脚本只在点击时通过 `GET /api/openapi/v1/subscriptions`（请求头 `X-OpenAPI-Key`）读取订阅，不会在页面启动时预取。接口支持 `media_type`、`limit` 和 `offset` 查询参数。脚本根据 `movie` 或 `tv` 与 TMDB ID 生成 TMDB 和 `https://hdhive.com/tmdb/{media_type}/{tmdb_id}` 跳转地址。

面板中的“页面入口显示”可以选择“识别到内容时”或“始终显示”。默认只在页面识别到链接后显示。

## 站点解锁

影巢、观影和癫影的资源详情页仍由站点自己完成解锁。脚本仅被动读取页面中已经出现的真实 115、magnet 或 ED2K 链接；识别成功后才显示对应按钮。脚本不会自动点击免费解锁、付费解锁、获取或查看，也不会绕过积分、验证码和权限限制。

在癫影页面中，脚本会监听正常解锁请求的返回内容。返回真实链接后，链接会出现在“已识别链接”列表中，用户可以手动选择转存、离线或外部推送。

## DIAN115 外部推送

切换到“外部推送”，填写实例根地址和 OpenAPI Key。面板中的“校验配置格式”不发网络请求；首次实际推送才验证服务是否启用、密钥是否有效及服务端目标目录配置。

外部推送的账号、目标目录和后续任务处理都由 DIAN115 服务端配置。

## 安全与边界

- 页面文本和接口响应都视为不可信输入，只接受严格协议与域名校验后的候选链接。
- 页面扫描限制锚点、特殊节点、普通文本节点数量和总字符数，避免在超大页面上无限扫描。
- 目录层级只由 CID 和父子浏览栈建立。任何远程 `name`、`fn`、`file_name` 都不会被切分、清理或用于推导层级。
- 用户脚本不是 `.d115p` 插件包，不应附带 `build/`、`releases/`、`.d115p`、私钥或主项目文件。
